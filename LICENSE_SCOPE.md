# License scope

Putting projects in one repository does not change their licenses.

| Material | Applicable scope |
| --- | --- |
| Existing PAL root code and documentation | Existing Apache-2.0 / CC BY 4.0 statements remain as recorded for that original material. |
| Newly retained PAL/workshop proof and receipt material | Existing author/source notices are preserved; no third-party work is relicensed by importing it. |
| projects/APCI and its separate manuscript supplement | No independently selected project license was found in the imported project. No new license grant is made here; the PAL root license must not be read as one. |
| projects/FRONT | Existing NOTICE and publication/source terms remain controlling. No new project-wide license is assigned. |
| external-audits/*/source or sources | The included upstream LICENSE applies to the exact upstream source subset. Upstream OpenAI authorship remains separate from the local audit. |
| Imported external-audit reports, scripts and receipts | Preserve their existing notices. The migration makes no new license grant beyond those notices. |

Source manuscripts, published deposits, dependencies and quoted material retain
their own terms. See each project's notices and immutable import record. A
repository-level license detector may not represent these separate scopes.
