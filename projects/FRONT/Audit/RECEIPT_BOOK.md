## What the mathematics earned

The answer and decision criteria use the actual reachable observations, with labels intact. Empty domains are handled without inventing an arbitrary unavailable answer. The future-output criterion is separate from the condition that permits updating the same stored representation.

Finite positive-rule propagation reaches its least closed set under the stated finite bound. Truth is conditional on the declared roots and truth-preserving rules. All conjunctive parents participate in that proof. An unsupported cycle does not supply its own root. The wake decomposition separates unfinished old consequences from the change attributable to the new seed within that fixed rule system.

The linear checks retain the actual maps in the BRIDGE exact sequence and one common generated baseline. The finite-horizon and finite-subfamily statements hold in arbitrary finite-dimensional input spaces; the horizon proof uses dimension drop as an alternative to the manuscript's Cayley–Hamilton argument. The side-trace result includes its lower bound and an attaining extension, with the residual query correctly typed on the quotient and its hidden injection. The extension is an existence result and does not price acquisition.

The correction model preserves the distinction that motivates this version: **a conclusion may have valid support while the offered old receipt fails**. Every retained alternative has its own grounded derivation. The explicit scratch transition checks its grant and postcondition before a changed-state commit; failures retain the original state and append their history. The finite prefix argument covers both successful and unsuccessful attempts.

The amortized-cost identity checks out in common units. The polynomial-accounting theorem retains initialization, the decreasing-rank bound, every productive step and the terminal check.

## Correction study: fresh runs and independent reaggregation code

The frozen FRONT-CORRECT-01 source and its 75 fixtures were run once normally and once with Python optimization. Each run retains 1,125 timed policy events: 75 cases, three arms and five technical repetitions. Each arm answers 216 distinct case/query questions; the five repeats are not five new datasets.

A separate data-only audit script, written in this same session, recomputed answers and receipt validity using an agenda-based Horn closure, recomputed summary counts and timing medians, and checked every logged timing partition. It imports none of the supplied policy, oracle or runner code. This supplies an additional code path, **not independent peer review**.

All four correction records—two supplied and two fresh—have identical substantive policy results:

| Measure | Unchecked continuation A | Blanket rechecking B | Selective correction C |
|---|---:|---:|---:|
| Correct support decisions | 132/216 | 216/216 | 216/216 |
| Invalid offered affirmative receipts | 114 | 0 | 0 |
| Valid affirmative receipts | 102 | 132 | 132 |
| Honest unresolved outcomes | 0 | 84 | 84 |
| Conclusions requalified with a different valid basis | 0 | 30 | 30 |
| Unnecessary blanket invalidations | 0 | 60 | 0 |

Of A's 114 invalid receipts, **30 accompanied conclusions that still had valid current support**. The other 84 were unsupported positive answers. B and C's 30 requalifications divide into 24 independent-alternative rescues and six changed-root/version rescues. Those are different kinds of recovery.

Each 96-case scratch-repair suite returned 16 unchanged supported states, 24 authorization denials, eight committed changes and 48 unresolved outcomes. Sixteen attempted changes failed revalidation and rolled back, retaining their failure records. Across the main fixtures, 21 requested actions received three permissions and 18 denials per arm; no action was executed.

The retained supplementary suite checks all 5,040 supplied row orders, 1,024 two-atom Horn systems with 2,048 questions, and 525 bounded cases. Budget outcomes are 408 exhausted/unresolved, 56 unresolved, 40 supported and 21 already stopped. Eight injected-error controls were detected. These remain finite tests under their supplied contracts.

The local wrapper supplies only the missing final resource-reporting interface and records peak RSS as **null/unknown**. The frozen runner, policy, oracle, fixtures and timers remain byte-identical. This is a local replay accommodation, not a manuscript edit or a silently fabricated measurement.

## What remains open

The [boundary controls](BOUNDARY-CONTROLS.md) show why omitted parents, stale receipts, lost labels, independently chosen baselines, unauthorized repairs and untransported return do not earn the stronger conclusions.

The larger open work is exactly the remaining coverage above, independent adversarial review, a proved Python-to-Lean refinement if desired, real-model or deployed-system evidence, and the separately scoped public/local Single-Cut comparison. The present finite study does not settle those questions. There were no paid/model calls, remote runs, delegated agents, app changes or public writes.

The work key's stopping condition is a complete, honest disposition—not a promise that every sentence acquires a theorem. This local companion leaves the manuscript unadopted and unpublished, with its substantive claims, experiments and unresolved bridges available for review.
