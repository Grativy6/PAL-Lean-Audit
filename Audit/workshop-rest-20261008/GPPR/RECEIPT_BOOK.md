**The main formal dependency remains explicit.** Gelfond-Schneider itself is not supplied as a checked library theorem. The golden specialization consumes a named hypothesis with the exact needed complex-base/logarithm and algebraic irrational exponent conditions. The Lean proof checks the golden application, not the long transcendence theorem. A separate [primary-source record](../GPPR-A/LITERATURE.md) verifies the required external theorem and convention in Ricci 1935. No custom axiom was introduced.

The polynomial argument does real work: finite-support integer coefficients are recovered through distinct addresses and nonzero algebraic weights. Algebraic scalar extension is proved through Mathlib's tower theorem. Signed valuations are independent of positive-rational numerator/denominator presentation. The actual Vogel weights are square roots, confirmed against the original equations, not the flattened text extraction.

**One fixture deserves a wording qualification:** G06 should distinguish exact ordered receipts from finite ribbon hashes. Different histories do not guarantee different arbitrary finite roots. The selected pair needs an actual root representation and an explicit collision/integrity condition. This leaves the exact endpoint theorem intact and agrees with the manuscript's existing security disclaimer. See the [cross-paper clarification](../CLARIFICATIONS.md).

The routing checks use typed local models. They do not establish a production router, efficient factor recovery, a floating-point separation guarantee, golden superiority, or a security protocol. Several guards are explicitly definition checks, not new mathematical claims. The density/no-global-separation sentence remains outside the finite-range pigeonhole proof.
